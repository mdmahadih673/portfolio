# Md. Mahadi Hasan — Portfolio

A modern, premium personal portfolio built with **Next.js**, **React**, **Tailwind CSS**, and **Framer Motion**.

## Sections

- Hero with animated particle background
- About Me with personal info cards
- Technical Skills with animated progress bars
- Software & Tools grid
- Featured Projects (6 cards)
- Experience Timeline
- Contact form with social links
- Footer

## Run locally

> **Note:** The `E:` drive in this workspace is nearly full (~1 GB total). Dependencies are installed at `C:\Users\USER 11\mahadi-portfolio`. Use that path to run the dev server, or free space on `E:` and run `npm install` here.

```bash
cd "C:\Users\USER 11\mahadi-portfolio"
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build for production

```bash
npm run build
npm start
```

## Deploy

Deploy to [Vercel](https://vercel.com) by connecting this repository. Next.js is optimized for Vercel out of the box.

## Tech stack

- Next.js 16 (App Router)
- React 19
- Tailwind CSS 4
- Framer Motion
